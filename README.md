# Weather App | Python 🌤️

A modern **Weather App built with Python and PyQt5** that allows users to search for a city and retrieve real-time weather information through a weather API.

## ✨ Features

* 🌍 Search weather information by city
* 🌡️ Display current temperature and weather conditions
* 💧 Display humidity
* 💨 Display wind speed and information
* ☁️ Weather condition visualization
* 🔄 Retrieve real-time weather data through an API
* 🖥️ Clean and interactive **PyQt5 graphical user interface**
* ⚠️ Handle invalid locations and API errors

## 🛠️ Technologies

* **Python 🐍**
* **PyQt5** - GUI development
* **REST API** - Weather data retrieval
* **JSON** - API response/data handling

## 🚀 Getting Started

Clone the repository, install the required dependencies, configure your weather API key, and run the application.

```bash
git clone https://github.com/qamro/Weather-App-Python.git
cd Weather-App-Python
pip install PyQt5
python main.py
```

## 🎯 Project Goal

This project was developed to practice **Python application development, PyQt5 GUI design, REST API integration, and JSON data processing** by building a practical real-world desktop application.
